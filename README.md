# Löslichkeit organischer Stoffe

Interaktive Simulation für den Chemieunterricht (erstellt von Markus Seitz): Mischversuche mit Stoffen aus sechs Stoffklassen
(Kohlenwasserstoffe, Alkanole, Alkanale, Alkanone, Alkansäuren, Ester) in Wasser und Benzin – Stoffebene (Spritzen, Dreiwegehahn)
und Teilchenebene (Wasserstoffbrücken, Keesom-, Debye- und London-Wechselwirkungen) im Vergleich.

**Simulation öffnen:** https://allerseitzcreator.github.io/Loeslichkeit/

Die Simulation besteht aus einer einzigen HTML-Datei (`index.html`, identisch mit `Loeslichkeit.html`) und läuft auch offline im Browser.
